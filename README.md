# 论脉 PaperTrace

**把一篇论文，读成一条走得通的论证。**

上传任意一篇 PDF，左栏放英文原文与学术中译逐段对齐，右栏写清这一段在做什么、在论证链的哪一环，底部一张表把全文逻辑摊开。解析与排版全部在浏览器里完成，文件不出这台设备。

线上地址：<https://baizigang21-coder.github.io/PaperTrace/>

---

## 为什么做这个

读论文最难的不是单词，是「这段话在整个论证里干什么」。翻译软件只给你意思，不给你位置；批注工具只给你空白，不给你结构。论脉把两件事压在同一页：

- 左边是**原句本身**，英文一字不改，下面接学术中译，公式、符号、引用段留在原位；
- 右边是**这一段的功能**：说的是什么、起什么作用、在论证链的哪一环；
- 底下是**全文骨架**：先给论证地图，再给逐段表，点一行跳回原文。

一条论证从问题、方法、证据走到结论的路径，在屏幕上是可以被看见的。

---

## 一页里有什么

| 区域 | 内容 |
| --- | --- |
| 左栏 · 原文 | 英文原段 + 学术中译，逐段对齐，段落号可定位 |
| 右栏 · 笺注 | 内容概括、段落作用、论证位置、一句人话解释（旁注四问） |
| 底部 · 逻辑表 | 论证骨架图 + 逐段表，覆盖摘要到结论 |
| 附 · 术语表 | 关键术语统一译名，可回查出现位置 |

## 功能

**读**
- 本地解析 PDF / 直接粘贴全文；双栏排版自动切成左右两列再排序
- 分章分段、逐段编号，摘要、引言、方法、实验、结论等小节标题全部保留
- 批量翻译 + 逐段笺注，失败批次自动重试，未完成段落标红后可单独重跑

**用**
- 马克笔高亮、段落笔记，右侧抽屉按「重点 / 笔记」分组
- 阅读时随时记录想法与疑问，标注跟随文稿保存
- 一键导出单页 HTML（可离线双击打开）与 PDF
- 加工完成的论文自动入库，文库可回看、可手动删除

**找**
- 内置文献检索，按关键词查论文并直接加入文库加工
- Zotero 连接：点一次自动拉起本机 Zotero 并读取其中的条目与附件

**看**
- 五套主题（纸白、暖纸、夜读、青瓷、墨蓝），随主题切换启动页与阅读页配色
- 启动页、新手引导、思维导图（把论证结构画成可拖拽的树）

## 两种跑法

1. **自备接口**：填一个 OpenAI 兼容的 `/chat/completions` 地址、模型名与 Key，一键批量跑完翻译与笺注。
   DeepSeek、硅基流动、OpenRouter、阿里百炼、Moonshot 这类允许浏览器直连的服务可以直接填；OpenAI 官方、火山方舟等会拦跨域请求，需要一个本机中转。
2. **复制提示词**：没有 Key 也能用。把内置提示词复制到任意大模型，把返回的 JSON 粘回来，产出的版式完全一致。

Key 只写进当前浏览器的 localStorage，不上传、不外传。

## 账户与额度

- 云端账户走 Supabase（邮箱注册 + 邮件验证），每篇加工消耗额度，额度用兑换码充值。
- 不登录也能用：文稿与标注只留在这台设备的浏览器里。
- 自建后端在 `server/`（FastAPI + SQLite），跑法见 `server/README.md`。

## 技术

- 单个 `index.html` 自包含，无构建、无框架，原生 JS + CSS
- PDF 解析、文本重排、渲染、导出全部在客户端完成
- 外部依赖只有 CDN 上的 PDF 库与字体，站点本身不含任何后端逻辑（除可选的账户接口）

## 部署

静态托管即可，仓库根目录放 `index.html`：

1. `Settings → Pages`，Source 选 `Deploy from a branch`
2. Branch `main`，目录 `/ (root)`
3. 保存后约一分钟生效，地址形如 `https://<用户名>.github.io/PaperTrace/`

改版：把新的 `index.html` 覆盖上传，Commit 后自动重建。

本地直接用浏览器打开 `index.html` 也能跑，功能不受影响。

---

## 边界

- 扫描版 PDF 没有文字层，需要先做 OCR，否则只能读到空白
- 超长论文按批次加工，一次跑完整篇会受模型上下文与速率限制
- 译文与笺注的质量取决于所用模型；术语表用于收敛译名，不保证与作者用法完全一致
- 文献检索依赖公开学术数据源，覆盖面不是全库
