这个工具在做什么

把一篇论文摊成三层：原文与译文并排，逐段说明它在论证里干什么，最后用一张表把全文的推理链和每一段的证据摊开。适合第一次读某个方向、或需要在两天内把一篇论文讲清楚的时候。

第一次来

打开就会看到一段五步的引导，指着屏幕告诉你在哪儿上传、在哪儿加工、在哪儿阅读；最后一步可以直接载入示例论文，把成品先看一遍。想重看，点右边「重看新手引导」，或按 ? 键。

三步跑完一篇

  1. 取原文：拖入 PDF（优先），或点「改为粘贴全文」。双栏 PDF 会自动按页面中线切成左右两列；跨栏断句、页眉页脚、连字符断词会在解析时处理。
  2. 核对切分：解析结果里会列出识别到的章节和段数。若某章没被识别，通常是标题写法特殊（全大写、只有编号），此时用「改为粘贴全文」并按 1 Introduction 这样的格式自己留出换行即可。
  3. 加工：填接口、模型名、Key，点「开始加工」。没有 Key 就复制提示词到外部大模型，把 JSON 粘回来，效果一样。

从 Zotero 直接取 PDF

用 Zotero 7 管文献时，「原文」栏里那张 ZOTERO 卡片可以直接列出最近的条目，点一条就把它的 PDF 取回本机解析——不用再去 Zotero/storage 目录里翻附件。

Zotero 没开也没关系：点「连接本机 Zotero」会先尝试唤起它（通过 zotero:// 协议），系统问「是否打开 Zotero」时选允许，等它起来后自动连上、直接取件。

前提装好 Zotero 7；在 设置 → 高级 允许本机其他应用与 Zotero 通信。个别版本还需要在 配置编辑器 里把 extensions.zotero.httpServer.localAPI.enabled 设为 true。 连不上常见是浏览器拦了本机请求、Zotero 里那次开关没开，或协议唤起被系统拦下。也可以绕开：在 Zotero 里右键附件 →「显示文件」，把 PDF 拖进上传区；或用「选择文件」直接选 Zotero/storage 里的 PDF。 隐私取回的是本机文件，只发给浏览器里的解析器，不经过任何服务器。

接哪个模型

接口地址任何 OpenAI 兼容的 /chat/completions，如 https://api.openai.com/v1、https://ark.cn-beijing.volces.com/api/v3、本地 http://localhost:11434/v1（Ollama）。 模型名按服务商给的名称填；翻译与标注建议用中英双语能力强的型号，温度会自动设低。 跨域浏览器直连要求服务端允许跨域（CORS）。若报 Failed to fetch，多为服务端未开放浏览器来源，改用本地代理或走「复制提示词」通路。 隐私Key 只写入本机 localStorage；论文文本只发给你填的那个接口，本站没有服务器。

提示词是什么口径

四类产出：译文（术语按统一表、保留英文原名）、功能标签（问题背景／反常现象／概念定义／关键证据／归因机制／干预方案／边界反证／局限路线）、段落作用（这段在做什么）、论证链位置（前提／诊断／处方／证据／限定）。另有一次全局综合，产出标题译名、三分钟速览、四个关键数字、六问档案、论证链条与术语表。

在阅读页做标注

读的时候可以直接用鼠标划词：选中原文或中译，屏幕上会浮出一条小工具条，三个动作——标为重点（留下一条底色）、写笔记（把这段和你的想法绑在一起）、复制。再点一次已划的重点，可以改笔记或取消重点。每个段落的右上角还有一个「＋笔记」，不划词也能记。

重点与笔记都存在这篇论文自己的记录里：换配色、换字号、关掉页面再打开都还在。右侧「我的标注」按段列出全部条目，点一条就跳回原处。

文库

一篇论文加工完成会自动入库，文库页按时间倒序列出它们的标题、页数、段数、重点与笔记数量。点开即回到那份笺注；每条右侧的「删除」会把它连同标注一起从本机删掉，删前要点两次确认。

导出与存档

导出单页把当前这篇连同译文、旁注、逻辑表打包成一个独立 HTML，双击即可打开，样式与阅读视图一致，适合发给同门或留作笔记；文件不含上传与接口功能。

导出 PDF把整篇排成适合纸张的版式：标题、三分钟速览、关键数字、四问档案、逐段原文与译文、每段的旁注与逻辑表一并输出；附录里的补充不再重复印刷，篇幅更省。点下去浏览器会弹打印对话框，目标选「另存为 PDF」即可存成文件——本机生成，不上传。

连不上怎么办

填好接口、模型、Key 却只报 Failed to fetch，多半不是 Key 的问题：请求根本没发出去，被服务端的跨域策略挡在浏览器里。

可直连DeepSeek、硅基流动、OpenRouter、阿里百炼、Moonshot——这几家会给浏览器放行。 会被挡OpenAI、火山方舟（豆包）、智谱——服务端不下发跨域响应头，浏览器里怎么填都连不上。 解法一换上面可直连的一家，多数有免费额度。 解法二本机运行 python relay.py（随站点附带的脚本），把「中转地址」填 http://127.0.0.1:8790，接口地址照常填原服务商。窗口关掉即停止中转。

如果报的是「服务端有回应，但没有正文」，说明接法已经通了，问题在模型的输出形态：推理型模型常把预算花在思维链上、正文留空，换成非推理模型即可；也可能是 max_tokens 太小，或模型名写成网关不认的部署名。日志会打印服务端原始返回的前几百字，照它对照就能判断。

不确定是哪一种，就点「测试连通」：它先打印实际请求的端点，失败时再探一次网络，明确区分「网络不通」「服务商不允许浏览器直连」「Key 或模型不对」「地址路径不对」。

边界

  • 扫描版 PDF（图片型）没有文字层，解析会得到空文本；需要先 OCR。
  • 公式、表格、图注在纯文本里会降级成线性文本，正文段落仍可读，但公式排版不还原。
  • 参考文献、附录默认不进笺注；如需保留，在解析结果里手动勾选章节。
  • 模型可能译错术语：页面把术语表放在每篇末尾，遇到关键概念以术语表与原文为准。

配色与字号

顶栏右上五枚色片即配色：纸白（默认，冷白灰，白天细读）、暖纸（奶油底，长读最护眼）、夜读（低亮度冷黑，夜里不刺眼）、青瓷（浅绿灰，少见光时的松弛感）、墨蓝（浅蓝灰，偏正式干练）。点一下即时生效并记住，启动页的底色也跟着换；A- / A / A+ 控制整体字号，正文与旁注同步缩放。

读不懂时先看这三处

  1. 全文逻辑地图：先读论证链条，知道这篇论文在打什么仗。
  2. 段落的「一句人话」：把术语换成日常说法，再回头看原文。
  3. 文末术语表：中英对照，防止被译名带偏。
